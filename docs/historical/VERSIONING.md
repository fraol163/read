# Versioning Policy

READ adheres to Semantic Versioning 2.0.0 (MAJOR.MINOR.PATCH).

## Version Numbering Schema

1. MAJOR version bumps when backwards incompatible architectural changes occur.
2. MINOR version bumps when new functionality or gates are added in a backwards compatible manner.
3. PATCH version bumps when backwards compatible bug fixes or mutator refinements are applied.

## Release Cadence

Releases occur upon successful completion of verification suites and automated packaging gates.
Every release binary is accompanied by cryptographic SHA-256 digests and provenance records.
